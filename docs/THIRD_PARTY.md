# Third-party sources

[Back to JARVIS](../README.md)

| Component | Authoritative source |
| --- | --- |
| Face tracking and ONNX models | [OpenSeeFace](https://github.com/emilianavt/OpenSeeFace), including its LICENSE and Licenses directory |
| Gesture component license | [Preserved Apache 2.0 text](../src/assistant_runtime/LICENSE.txt) |
| Gesture recognition and task model | [Google MediaPipe](https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer/python) |
| YOLO26 weights and runtime | [Ultralytics YOLO26](https://docs.ultralytics.com/models/yolo26/) |
| Multimodal embeddings | [Qwen3-VL-Embedding-2B model card](https://huggingface.co/Qwen/Qwen3-VL-Embedding-2B) |
| Apple Silicon transcription | [MLX Whisper](https://github.com/ml-explore/mlx-examples/tree/main/whisper) |
| Other-platform transcription | [OpenAI Whisper](https://github.com/openai/whisper) |
| Gemini client | [Google Gen AI Python SDK](https://github.com/googleapis/python-genai) |
| Speech playback and synthesis | [ElevenLabs Python SDK](https://github.com/elevenlabs/elevenlabs-python) |
| Smart plugs | [python-kasa](https://github.com/python-kasa/python-kasa) |
| Servo firmware dependency | [Arduino Servo library](https://github.com/arduino-libraries/Servo) |

The root project has no newly assigned license. Each external dependency, model, and API retains its own license or service terms; the existing gesture-component license does not automatically cover the whole repository. Third-party source and model downloads retain their upstream notices.
